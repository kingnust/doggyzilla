# DOGZILLA-specific IMU calibration

`imu.json` is generated by the guided calibration command:

```bash
./deploy/dogzilla-map imu-calibrate
```

The file contains the measured signed axis transforms, acceleration scale,
stationary gyro bias, sample covariances, and timing statistics for this
physical robot. Keep it with the robot's backup. The fused mapping profile
refuses to start when the file is absent or its six-pose validation is false.

Do not copy another robot's `imu.json`: bias and scale are hardware-specific.
